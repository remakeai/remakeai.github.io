Robots Need an App Store

The Problem

Every robot ships with its own app. Its own cloud. Its own limited set of features. When the company stops updating, the robot stagnates.

  • Robot vacuums clean, but can't play games
  • Quadruped robots do tricks, but run out of tricks
  • Companion robots are islands — no ecosystem, no new apps
  • Developers can't build for robots (no SDK, no distribution)
  • Consumers are stuck with whatever the manufacturer ships

Sound familiar? This is mobile phones before the App Store.

The Opportunity

What if robots had a shared platform?

  • Manufacturers focus on great hardware
  • Developers build apps that run on ANY robot
  • Consumers get an ecosystem that grows over time
  • New use cases emerge that no single company imagined

This is what we're building.

Why Now

Home robots are reaching critical mass. 50M+ robot vacuums sold annually. Quadrupeds entering consumer market ($1,600 Unitree Go2). Humanoids on the horizon (2025-2030). Consumer comfort with robots is mainstream.

The hardware is ready. The platform layer is missing. remake is that platform layer.

Technical baseline for platform compatibility. Most modern navigation-capable robots already meet these requirements.

✓ 2D or 3D spatial awareness
✓ Autonomous navigation
✓ Onboard compute (Linux preferred)
✓ WiFi connectivity
✓ API for movement commands
